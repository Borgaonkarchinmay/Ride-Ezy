# 🏍️ Ride-Ezy

A bike-pooling platform designed to help university students find and share rides.

### Features
- **Ride Listings:** Create and explore ride listings to connect with fellow students.
- **Trip Visualization:** View trips on an interactive map.
- **Distance Insight:** Get distance information for planned trips.

### Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Maps & Geocoding:** Mapbox, Geocode Earth APIs

**Note:** This project is locally hosted and is not currently deployed.
